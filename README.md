# ExamScope AI

ExamScope AI is an AI-powered exam preparation platform for students.

It combines a Next.js web application with a FastAPI AI/document-processing backend to help students organize subjects, upload study materials, analyze past papers, generate evidence-grounded questions, build mock exams, review saved revision content, and use an AI study assistant.

## Project Structure

```text
examscope-ai/
├── frontend/   # Next.js web application
└── backend/    # FastAPI AI and document-processing service
```

## Main Features

- User authentication
- Subject management
- Study document uploads
- PDF, DOCX, PPTX and TXT processing
- Past paper analysis
- Topic discovery
- Exam-topic predictions
- MCQ generation
- Structured question generation
- Essay question generation
- Evidence-grounded answers
- Study Assistant
- Saved revision questions
- Mock exam builder
- Analytics dashboard
- Responsive and accessible student UI
