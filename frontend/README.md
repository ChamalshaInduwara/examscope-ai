# ExamScope AI

ExamScope AI is an AI-powered exam preparation platform that helps students organize study materials, analyze past papers, generate questions, create mock exams, review saved questions, and study using evidence-grounded AI assistance.

## Tech Stack

### Frontend
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts

### Backend
- FastAPI
- Python
- Pydantic
- Sentence Transformers
- Gemini / OpenRouter

### Data and Storage
- PostgreSQL
- Prisma ORM
- S3-compatible object storage

## Main Features

- User registration and authentication
- Subject management
- Study document uploads
- Document processing and text extraction
- Past paper analysis
- Topic discovery
- Exam-topic predictions
- MCQ, structured and essay question generation
- Evidence-backed answers
- Study Assistant
- Saved revision questions
- Mock exam builder
- Student analytics dashboard
- Responsive and accessible student interface

## Project Structure

```text
examscope-ai/
├── frontend/   # Next.js web application
└── backend/    # FastAPI AI/document-processing service
```

## Prerequisites
Install the following before starting:

- Node.js 20+
- npm
- Python 3.12+
- PostgreSQL database
- S3-compatible object storage
